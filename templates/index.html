استوديو الصور المتقدم

معالجة محلية متعددة المحركات داخل GitHub Codespaces.

LOCAL AI
01

وجه مرجعي ← عدة صور مستهدفة

جودة قياسية أو عالية أو فائقة، مع Pixel Boost ومُحسّن وجه وSuper Resolution عند توفر المحرك.

02

رفع الجودة إلى جودة فائقة

Super Resolution حقيقي، مع دعم تحسين الوجه والناتج النهائي، وليس مجرد تكبير عادي.

2×سريع
4×فائق
8×Ultra عند توفر الموارد
03

نقل الوضعية

مرجع واحد ← عدة مستهدفين. الواجهة مجهزة للربط مع Pose/ControlNet محلي.

المحرك لم يُفعّل بعد؛ لن يظهر زر تنفيذ وهمي قبل تركيب نموذج Pose/ControlNet فعليًا.
04

تحرير وتركيب متقدم

طبقات، أقنعة، إزالة عناصر، تغيير خلفية، inpainting وoutpainting عبر طبقة ComfyUI محلية عند تفعيلها.

منطقة العمل
هذه الواجهة جاهزة لطبقة ComfyUI، لكن محرك التوليد لن يُعتبر مفعلًا قبل تشغيله وربط Workflow فعلي.
05

وصف الصور بالتفصيل

يدعم نموذج رؤية محلي عبر Ollama عند تفعيله.

06

استرجاع الصور

هذه الوظيفة تحتاج وسيط تخزين متاحًا للمحرك.

Codespaces لا يرى القرص الداخلي أو USB الموجود في جهازك مباشرة. يمكن ربط Self-Hosted Runner أو تشغيل PhotoRec على جهاز متصل بالقرص.
